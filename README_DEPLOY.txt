DEPLOYMENT
1. Copy the contents of this folder to the root of the GitHub repository used for the ePortfolio.
2. In index.html, replace REPLACE_WITH_CODE_REVIEW_VIDEO_URL with the public or unlisted URL of the recorded code review video.
3. Commit and push the files.
4. In GitHub repository Settings > Pages, deploy from the main branch and root folder if Pages is not already enabled.
5. Open the published GitHub Pages URL and verify every navigation link and download.
6. Submit that URL with the required course files.

IMPORTANT
The course rubric requires the recorded code review video. Add the video URL before final submission.

The repository contains source/original and source/enhanced so the original and final source files are present in the repository as well as downloadable ZIP files.
